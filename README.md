# Mesa

Dividí la cuenta cuando te juntás a comer con amigos.

Cargá lo que se pagó, copiá el reparto y mandalo al grupo. Sin vueltas.

## Qué hace

- Mesas con personas, gastos y quién pagó
- Propina, alias de Mercado Pago y marcar transferencias hechas
- Resumen por persona y el porqué de cada movimiento
- Grupos recurrentes para armar la próxima mesa en un toque
- Instalarla en el celular como una app

Los datos quedan en este dispositivo.

## Desarrollo

```bash
npm install
npm run dev
```

```bash
npm run build
```
